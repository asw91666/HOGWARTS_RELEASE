# Demo code

## Inference HOGWARTS on images

If you have images that you want to run inference on, place them directly in `./example/` (e.g., `./example/photo.jpg` or `./example/photo.png`) and execute the code. This will save the results in `./example/demo_results/`.

Please run the following code in the repository root directory.

```bash
PYOPENGL_PLATFORM=egl python hogwarts_demo.py
```
